# Questions ouvertes : fin de thèse (M13a, M13b, M13c)

Ouvertes le 2026-11-18. **Aucune réponse ici** : chaque réponse vient d'un texte
consulté (lien et date de consultation, comme `arrete-2016-article-13.md`) ou d'une
personne nommée (rôle, date). Rien n'est déduit de mémoire. Les numéros d'articles
sont ceux de `plateforme_these.tex`, **à vérifier** sur la version consolidée de
Légifrance avant d'être cités ailleurs.

Tant qu'une question est ouverte, le code garde le comportement prudent noté dans la
fiche `docs/modules/M13-fin-de-these.md` (colonne « En attendant »).
